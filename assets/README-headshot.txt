HEADSHOT INSTRUCTIONS
=====================

Place your professional photo in this folder and name it exactly:

    headshot.jpg

Tips for a good result:
- Square image works best (e.g., 600 x 600 pixels or larger).
- Head-and-shoulders, good lighting, plain or simple background.
- JPG or PNG is fine — if PNG, name it headshot.jpg anyway OR tell me and
  I'll update the file reference in index.html.

If no photo is present, the site simply shows a neutral "Photo" placeholder,
so the page still works fine without it.
